Entry for [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) on make.fun.

The program writes one fortune cookie message to `/output/entry.txt`: a
fortune for a software engineer, short and declarative, whose twist comes
from the engineer's world — code that works on the first try, taken away
again because it is someone else's. The gate requires 1–120 characters
of UTF-8 text on one line; this entry is 79 characters on one line.

> Your code will work on the first try. Unfortunately, it is someone else's code.

The fortune opens generous and takes it back in the same breath — the
classic cookie shape, with the sting coming from the engineer's world
rather than a generic slogan.

Run with Node 22+:

```sh
node main.ts
```
